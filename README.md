# API de Gastos Públicos

API REST desenvolvida com Laravel para gerenciamento, análise e transparência de despesas públicas do estado de Pernambuco.

## 🚀 Sobre o Projeto

Este projeto foi desenvolvido na disciplina de Backend com o objetivo de aplicar conceitos de desenvolvimento de APIs REST, arquitetura MVC e integração com banco de dados relacionais.

A aplicação permite importar dados reais de despesas públicas, realizar consultas detalhadas e gerenciar gastos vinculados a órgãos públicos.

---

# 📊 Funcionalidades

## 🏛️ Órgãos Públicos

* Cadastro de órgãos públicos;
* Atualização e exclusão;
* Ranking de gastos por instituição.

## 💰 Gastos Manuais

* Cadastro de despesas;
* Atualização parcial;
* Exclusão de registros;
* Associação com órgãos públicos.

## 📈 Despesas Públicas

* Importação de dados JSON;
* Listagem paginada;
* Filtros mensais;
* Comparativos trimestrais;
* Indicadores automáticos:

  * Total de despesas;
  * Média de gastos;
  * Maior despesa;
  * Menor despesa.

# 🎯 Objetivo

O projeto busca demonstrar como a tecnologia pode contribuir para maior transparência pública e melhor acesso às informações sobre gastos governamentais.

Além disso, representa minha evolução no desenvolvimento backend utilizando boas práticas de programação e organização de sistemas.
